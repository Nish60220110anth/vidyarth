# Vidyarth Platform Overview

## Introduction

**Vidyarth** is a centralized platform designed to support students through every stage of the placement process

- Provides access to detailed company information, job descriptions, and domain-specific preparation resources across Consulting, Finance, Marketing, Product Management, and more
- Students can view their shortlists, track CV submissions, explore curated videos, and stay updated with the latest placement-related news and announcements
- Offers Mock interview features and personalized dashboards, helping students stay organized, informed, and fully prepared for opportunities ahead.

---

## 1. STUDENT Functionality

| Feature             | Description                                                                             |
|---------------------|-----------------------------------------------------------------------------------------|
| **Dashboard**       | View personalized overview including announcements, shortlists, and recommended content |
| **Company Section** | Browse companies, view job descriptions, logos, and preparation content                 |
| **News Section**    | Read the latest placement news, tagged by domain or company, with date filtering        |
| **CV Prep**         | Access CV guidelines, examples, and CV-related announcements                            |
| **Domain Prep**     | Explore preparation material for domains like Consulting, Finance, Marketing, etc.      |
| **Mock Interviews** | Practice through AI-powered or manually scheduled mock interviews                       |
| **Shortlists**      | View current and past shortlists; download JD and prep resources                        |
| **My CV**           | View and download your verified CV(s)                                                   |
| **Profile**         | Edit personal details and preferences                                                   |
| **Announcements**   | View company-specific or platform-wide announcements                                    |
| **Videos**          | Watch curated, domain- and company-tagged videos                                        |
| **Compendium**      | Browse and download multi-domain/company PDF resources                                  |

---

## 2. DISHA & Placement Committee Functionality

| Feature                | Description                                                                 |
|------------------------|-----------------------------------------------------------------------------|
| **Manage Companies**   | Add/edit/delete companies, update logos and tag domains                     |
| **Manage JD**          | Upload/edit JD files, associate with domains and placement cycles           |
| **Manage News**        | Create, tag, and publish domain-specific or company-specific news           |
| **Manage Videos**      | Add/edit video entries, upload thumbnails, embed YouTube videos             |
| **Manage Cohort**      | Assign DISHA coordinators, set PCOM IDs, and edit student cohort data       |
| **Upload CVs**         | Manage CV submissions, status, and approval workflows                       |
| **Send Emails**        | Trigger event-based emails with pre-designed HTML templates                 |
| **Notifications**      | View, test, and mark email notifications as handled                         |
| **Placement Cycles**   | Create and manage job cycles; tag them active/inactive                      |
| **Analytics/Tracking** | Monitor video views, CV downloads, and platform engagement (planned)        |

---

## 3. Cross-Role Functionality

| Feature                    | Description                                                                 |
|----------------------------|-----------------------------------------------------------------------------|
| **Email Templates**        | Styled HTML templates with dynamic placeholders based on notification type  |
| **Firebase Storage**       | Secure storage for all PDFs, JD files, and thumbnails                       |
| **Role-based Sidebar**     | Dynamic sidebar with access-control based on user role                      |
| **Responsive Design**      | Fully mobile-optimized design across all pages and components               |
| **Search & Filters**       | Powerful filtering across lists (company, domain, date, keywords)           |
| **Animations & UI Polish** | Framer Motion animations, tooltips, skeleton loaders, hover states, spinners |
